# Design and UX Rules

## Product feel
A welcoming, modern café experience: clean, warm, readable, fast, and mobile-first. Avoid an overly complex enterprise dashboard.

## Visual direction
- Neutral/cream background with dark readable text and one restrained accent color.
- Clear type scale and generous spacing.
- High-contrast prices and prominent add-to-cart controls.
- Consistent button, input, card, badge, and dialog styles.
- Real images only when available; do not use broken image URLs or imply sample content is real.

## Customer menu
- Café name and optional location/opening information.
- Category navigation that works on touch screens.
- Menu item name, short description, price, availability, and image if available.
- Visible cart count and total.
- Clear unavailable state and disabled add action.
- Cart quantity controls usable on narrow screens.
- Accessible labels, focus styles, and keyboard operation.

## Owner dashboard
- Prioritize new orders and current status.
- Display order reference, time, items, quantities, and total.
- Confirm status-changing actions where accidental updates are costly.
- Show loading, empty, and failure states.

## Responsive and accessibility requirements
- Test a narrow phone viewport, tablet, and desktop.
- Avoid horizontal page overflow.
- Use semantic headings, form labels, meaningful alt text, and keyboard focus.
- Do not rely on color alone to communicate order state.
- Respect reduced-motion preferences if animations exist.

## Scope control
Under a one-hour deadline, fix usability defects in core paths first. Do not redesign all pages or add animation-heavy effects.
