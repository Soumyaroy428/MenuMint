# Ordered Implementation Tasks

Only work on the next task after reporting the current task's result and receiving permission to continue.

## P0 — Discover and baseline
- [ ] CP-00 Confirm repository root.
- [ ] CP-01 Inspect directory structure.
- [ ] CP-02 Read project instructions and docs.
- [ ] CP-03 Inspect Git state without discarding changes.
- [ ] CP-04 Inspect dependencies and scripts.
- [ ] CP-05 Record baseline errors and build/test status.

## P1 — Minimum viable path
- [ ] CP-06 Confirm architecture and data flow.
- [ ] CP-07 Validate environment configuration safely.
- [ ] CP-08 Confirm app starts.
- [ ] CP-09 Verify public café menu route.
- [ ] CP-10 Verify categories/items/price/availability.
- [ ] CP-11 Verify cart behavior.
- [ ] CP-12 Verify server-side order validation and pricing.
- [ ] CP-13 Verify owner dashboard authentication and tenant isolation.
- [ ] CP-14 Verify order status updates.
- [ ] CP-15 Add/fix essential loading, empty, error, and success states.

## P2 — Release checks
- [ ] CP-16 Run relevant lint/typecheck/tests.
- [ ] CP-17 Run production build.
- [ ] CP-18 Review diff, secrets, and regressions.
- [ ] CP-19 Verify production config requirements and risks.
- [ ] CP-20 Prepare pre-deployment report and request permission to push if needed.
- [ ] CP-21 After separate push approval, push only the approved changes.
- [ ] CP-22 Request separate explicit Vercel deployment approval.
- [ ] CP-23 After deployment approval, deploy and smoke-test the live URL.
- [ ] CP-24 Deliver final release report.

## P3 — Defer if deadline is under one hour
- [ ] SaaS subscriptions/billing.
- [ ] Advanced analytics.
- [ ] Loyalty, coupons, delivery fleet, kitchen display.
- [ ] Real payment gateway setup if not already configured.
- [ ] Multi-location inventory.
- [ ] Large-scale redesign or architectural migration.
